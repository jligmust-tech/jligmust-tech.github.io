About

What this site tracks, how scores are defined, and what is still pending.

Purpose

Why scAI Index exists.

Single-cell foundation models (scGPT, Geneformer, scFoundation, CellPLM, …) are proliferating, and general LLMs are increasingly used for scRNA-seq interpretation. This site aggregates both into one comparable, sortable hub.

Methodology — working draft

Metric definitions, pending finalization with real data.

  • Cell-Type Annotation ↑ — zero-shot cell-type classification accuracy/F1 on benchmark datasets (e.g. CellxGene subsets). Higher is better.
  • Batch Correction ↑ — integration quality across batches (e.g. iLISI / ASW). Higher is better.
  • Gene-Set Analysis ↑ — LLM ability to interpret gene sets (pathway/enrichment reasoning). Higher is better.
  • sc Analysis Code ↑ — LLM ability to write correct analysis code (scanpy/seurat workflows). Higher is better.

Data policy

Honest about the current state.

Current status: sample/placeholder data. All scores on this site are framework placeholders and must NOT be cited or relied on. Real values will be researched from primary papers and official repositories, with sources linked, before any number is published as final.
