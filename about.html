About

What this site tracks, how current scores are defined, and where evidence is still missing.

Purpose

Why scAI Index exists.

Single-cell foundation models (scGPT, Geneformer, scFoundation, CellPLM, …) are proliferating, and general LLMs are increasingly used for scRNA-seq interpretation. This site aggregates both into one comparable, sortable hub.

Methodology — current snapshot

Definitions used by the data currently shown.

  • Annotation ↑ — reported cell-type annotation accuracy or binary agreement; the setting may be supervised or use a frozen backbone and is stated in the row notes. Higher is better.
  • Batch Integration ↑ — Avg. Batch from a single-cell integration benchmark such as scIB; it is not interchangeable with annotation accuracy. Higher is better.
  • Annotation Agreement ↑ — LLM binary agreement by cell with manual labels in the AnnDictionary Tabula Sapiens v2 evaluation. Higher is better.
  • Gene-Set Terms ↑ — proportion of biological-process terms recovered in the AnnDictionary evaluation. Higher is better.
  • Workflow Accuracy ↑ — scBench accuracy over verifiable executable scRNA-seq workflow tasks; this is a workflow/agent proxy, not isolated code generation. Higher is better.
  • Parameters / Pretrain Cells — source-reported model scale; versions are separate where relevant.

Data policy

Honest about the current state.

Current status: source-linked snapshot. Every populated value has a source in the row data. A null/dash means no compatible published value was found, not zero. Because source papers use different datasets and protocols, values should not be treated as a universal ranking; inspect the notes and source links.
