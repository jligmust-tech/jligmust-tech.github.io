Welcome to scAI Index

This site tracks two fast-moving categories of models relevant to single-cell research:

  1. Single-cell foundation models — transformer-based models pretrained on scRNA-seq atlases (scGPT, Geneformer, scFoundation, CellPLM, UCE, …).
  2. General LLMs applied to single-cell tasks — GPT, Claude, DeepSeek, Gemini, Llama used for cell-type annotation, gene-set interpretation, and writing analysis code.

Why? Because choosing a model for a single-cell workflow today means comparing papers, repos, and ad-hoc benchmark claims across two very different model families. The goal of scAI Index is to put both on one sortable leaderboard with defined, source-linked metrics.

Current status

Framework preview. The site structure is live; all scores are placeholder values. The About page tracks the roadmap: finalize metric definitions, then populate data from primary papers with sources attached.

How to add a blog post

Copy this file into blog/posts/ with a new name, edit the content, then add a matching entry to the posts array in assets/js/data.js. The list on the Blog tab and the updates feed on the home page update automatically.
