How the leaderboard metrics are defined

The leaderboard keeps several evidence types visible instead of collapsing them into one unsupported composite score. Each row carries a note describing the dataset, task, and evaluation setting behind its populated values.

Single-cell foundation models

  • Annotation ↑ is the reported cell-type annotation accuracy or agreement. The current populated rows include supervised transfer results from the CellPLM comparison table and an average accuracy reported for CellFM.
  • Batch Integration ↑ is the reported Avg. Batch value from the UCE integration comparison. It is not the same measurement as annotation accuracy.
  • Parameters / Pretrain Cells are source-reported scale fields. Versions are separated where a model family has materially different checkpoints.

General LLMs

  • Annotation Agreement ↑ is binary agreement by cell with manual labels in the AnnDictionary Tabula Sapiens v2 evaluation.
  • Gene-Set Terms ↑ is the proportion of biological-process terms recovered in that same evaluation.
  • Workflow Accuracy ↑ is the accuracy reported by scBench across executable scRNA-seq workflow problems. It is a workflow/agent score, not isolated code-generation accuracy.

Nulls are intentional

A dash means that no compatible published value was found in the checked sources. It does not mean zero, and it does not imply that a model was tested and failed. Scores from different studies should be compared only within a shared dataset and protocol.
