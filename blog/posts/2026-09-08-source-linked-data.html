First source-linked leaderboard snapshot

The first research pass replaces the scaffold’s demo numbers with source-reported metadata and published evaluation snapshots. The current data file contains 35 model rows and 40 populated numeric score cells across foundation-model and general-LLM sections.

The foundation-model entries draw on official model repositories and primary papers for scGPT, Geneformer, scFoundation, CellPLM, UCE, scBERT, scMulan, GeneCompass, scPRINT, and CellFM. The general-LLM entries connect AnnDictionary’s marker-based evaluation with scBench’s executable workflow benchmark.

Coverage is intentionally uneven. A model may have a documented parameter count and pretraining corpus but no compatible public score in the current sources. Those cells stay null and render as a dash. This keeps the snapshot auditable while the longer-term goal remains harmonized evaluation on shared datasets and protocols.
